# C# 학습 레포지토리

C# 기초부터 Unity 연동까지 단계별로 학습하는 레포지토리입니다.

## 기술 스택

- Language: C#
- Runtime: .NET 9
- IDE: JetBrains Rider

| 02 | 변수, 데이터 타입, 연산자 |
| 03 | 조건문과 반복문 |
| 04 | 배열과 컬렉션 (List, Dictionary) |
| 05 | 메서드 (함수) |
| 06 | 클래스와 객체 (OOP 기초) |
| 07 | 상속과 다형성 |
| 08 | 인터페이스와 추상 클래스 |

| # | 주제 |
